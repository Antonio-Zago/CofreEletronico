# Mobile

App Flutter do Cofre Eletrônico (Riverpod, go_router, dio, google_maps_flutter, geolocator, qr_flutter, Firebase Messaging).

O projeto Flutter é criado na T-0104, organizado por feature (`lib/features/<feature>/`) e com flavors dev/prod.

Responsável: agente `mobile-flutter`. Detalhes em [../docs/ARQUITETURA.md](../docs/ARQUITETURA.md).
